# Idea template

Fill in every section. An empty section means the idea is not ready.

```markdown
# <Short name>

**Problem:** What is wrong or unknown, specifically.
**Why it matters:** What changes if this is answered.
**Research question:** One question that an experiment could answer.

## Hypotheses
- H1: a specific, testable claim.
- H2: a competing explanation.
- H0: the conservative alternative you would accept.

**Assumptions:** What must hold for the test to mean anything.
**Scope:** What is in and out.
**Mechanism:** How it would work, and why that could address the problem.
**Mathematics (optional):** Define every symbol and assumption.

## Prior work
- Confirmed by a search: ...
- From memory, still to verify: ...

## Experiment plan
- Datasets:
- Baselines:
- Metrics:
- Ablations:
- Controls:
- Compute: rough scale.
- Minimum viable experiment: the cheapest test that could change your mind.
- Stages: Stage 1 ...; Stage 2 only if stage 1 gives ...

## Expected outcomes
- If H1: what you would see.
- If H2: what you would see instead.
- If H0: what you would see instead.

## When to stop
- Falsified if: a specific result that would disprove H1.
- Stop if: when to abandon the work.

- Data:

- Evaluation:
```
